# Vremenske postaje

Go modul za upravljanje vremenskih postaj in njihovih temperaturnih meritev.

## Funkcionalnosti

- Ustvarjanje vremenskih postaj.
- Dodajanje temperaturnih meritev.
- Izračun osnovne temperaturne statistike.
- Izpis meritev in temperaturnih poročil.
- Nastavljanje dovoljenega temperaturnega območja.
- Nastavljanje najmanjšega števila meritev za izračun statistike.

## Zagon programa

Program zaženemo z ukazom:

```bash
go run .
